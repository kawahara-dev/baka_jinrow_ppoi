遊び方

・8人でスタート。あなた1人＋CPU7人。

・フェーズ順：夜行動 → 朝の報告 → 昼の議論 → 投票。

・夜の解決順：妨害 → 護衛 → 調査・盗み見 → 爆弾設置 → 追跡・見張り → 襲撃 → 爆発（前日の爆弾）。

・昼は「報告→議論→投票」を順番に進行し、各フェーズで操作が制限されます。

・イノセント陣営はインポスター全員追放で勝利、インポスター陣営はイノセントと同数以上で勝利。

・約半分のゲームでは第三勢力「ボマー」も登場。最後の1人になるか、爆弾で2人以上倒して生き残ると勝利するのでご注意。

・インポスターが1人だけのときは、襲撃に加えて役職の能力（妨害／盗み見）も使える本気モードになる。

・占い師には結果がズレる個体が混ざることがある（本人にも分からない）。

・パス＆プレイでは2〜8人で1台の端末を回して遊べます。役職は受け渡し画面で順番に確認し、夜行動と投票も順番に入力します。議論は口頭で行い、タイマー（設定で なし／1分／2分／3分）で時間を計れます。戦績はソロと別に記録されます。
