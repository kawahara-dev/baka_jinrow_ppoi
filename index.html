遊び方

・8人でスタート。あなた1人＋CPU7人。

・フェーズ順：夜行動 → 朝の報告 → 昼の議論 → 投票。

・夜の解決順：妨害 → 護衛 → 調査・盗み見 → 爆弾設置 → 追跡・見張り → 襲撃 → 爆発（前日の爆弾）。

・昼は「報告→議論→投票」を順番に進行し、各フェーズで操作が制限されます。

・ピュア陣営はフェイク全員追放で勝利、フェイク陣営はピュアと同数以上で勝利。

・約半分のゲームでは第三勢力「ボマー」も登場。最後の1人になると単独勝利するのでご注意。

・一部のピュア役職は「うっかり」で結果がズレることあり！
