# Fake Bloom

ピュア陣営とフェイク陣営に分かれて戦う、ブラウザで遊べる正体隠匿（人狼系）ゲームです。
あなた1人＋CPU7人の8人対戦で、インストール不要・単一HTMLファイルで動作します。

**▶ 遊ぶ： https://kawahara-dev.github.io/baka_jinrow_ppoi/**

## 遊び方

1. START を押してゲーム開始。自分の役職が表示されます。
2. フェーズは **夜行動 → 朝の報告 → 昼の議論 → 投票** の繰り返しです。
3. 夜は役職の能力（調査・護衛・追跡・襲撃など）を使い、昼は発言とログの矛盾を探して、投票で怪しい1人を追放します。
4. フェイク陣営を全員追放すればピュア陣営の勝ち。ピュア陣営がフェイク陣営と同数以下まで減るとフェイク陣営の勝ちです。

## 役職

| 役職 | 陣営 | 能力・特徴 |
|---|---|---|
| 見習い占い師 | ピュア | 夜に1人の陣営を調べる |
| 守り手 | ピュア | 夜に1人を襲撃から守る（自分も可） |
| 追跡係 | ピュア | 夜に1人が「誰を訪ねたか」を知る |
| うっかり占い師 | ピュア | 占い結果が45%の確率でランダムにズレる |
| 村ガール | ピュア | 能力なし。議論と投票で戦う |
| ポリス | ピュア | 夜に1人を訪ねて、その夜の行動を封じる（フェイク陣営の襲撃そのものは止められない）。ピュア側の役職は抽選で登場 |
| 見張り役 | ピュア | 夜に1人の家を見張り、その夜に訪れた全員が分かる。ピュア側の役職は抽選で登場 |
| トラッパー | ピュア | 夜に1人の家へ罠を設置。その人が襲撃されて倒れたら、襲撃者も道連れになる。ピュア側の役職は抽選で登場 |
| ドクター | ピュア | 夜に1人を診察。その人がその夜に襲撃や爆発で倒れたら、朝までに蘇生させる。ピュア側の役職は抽選で登場 |
| マウス | ピュア | 昼の役職。ゲーム中1回だけ、議論中に1人の本当の役職を全員に公開できる。ピュア側の役職は抽選で登場 |
| 政治家 | ピュア | 投票の役職。自分の票が常に2票分になる。ピュア側の役職は抽選で登場 |
| フェイクガール | フェイク | 夜に1人を脱落させる（襲撃は陣営で1回）。襲撃しない夜は、ピュア側1人の夜行動を妨害する |
| なりすまし | フェイク | 調査されると65%の確率でピュア判定に化ける。襲撃も担当でき、襲撃しない夜はピュア側1人の実役職を盗み見する（陣営はその情報を襲撃先の決定に使う） |
| ボマー | ニュートラル | 第三勢力。約半分のゲームに登場。夜に1人へ爆弾を仕掛け、翌日の夜に爆発する（護衛されていると不発）。どちらの陣営の勝利条件にも数えられず、最後の1人になるか、爆弾で2人以上を倒して生き残ると勝利 |
| バカ | ピュア | 本人には別のピュア役職が表示され、その役職として夜行動する。ただし行動結果はすべて偽物（占い判定はランダム、護衛は実際には守れない、追跡・見張り情報もデタラメ、ポリスの妨害・トラッパーの罠・ドクターの蘇生・マウスの公開もすべて空振りや偽物になる）。脱落時に実役職が公開される |

キャラクターは ルナ、ミオ、ユイ、カノン、スズ、リリ、ノア、エマ の8人です。

## 技術メモ

- `index.html` の単一ファイル構成（HTML / CSS / JavaScript、ビルド不要）
- タイトル画面では、8人のキャラクターが「てちてち歩行」のパレードアニメーションで横切る。各キャラに全身イラストの歩行2ポーズ（左足前／右足前）を用意し、フレーム切り替え＋体の上下動で本当に足を運んで歩くように見せている。歩行用画像はバイナリを直接置けない都合で `walk/<名前>_a.b64` / `_b.b64`（base64テキスト）として保存し、ページ読み込み時に data URI へ復元している
- ローカルで試す場合は `index.html` をブラウザで開くだけで動作します
- GitHub Pages で `main` ブランチのルートを公開しています
