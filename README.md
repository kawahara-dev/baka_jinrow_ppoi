# Fake Bloom

ピュア陣営とフェイク陣営に分かれて戦う、ブラウザで遊べる正体隠匿（人狼系）ゲームです。
あなた1人＋CPU7人の8人対戦で、インストール不要・単一HTMLファイルで動作します。

**▶ 遊ぶ： https://kawahara-dev.github.io/baka_jinrow_ppoi/**

## 遊び方

1. START を押してゲーム開始。自分の役職が表示されます。
2. フェーズは **夜行動 → 朝の報告 → 昼の議論 → 投票** の繰り返しです。
3. 夜は役職の能力（調査・護衛・追跡・襲撃など）を使い、昼は発言とログの矛盾を探して、投票で怪しい1人を追放します。
4. フェイク陣営を全員追放すればピュア陣営の勝ち。ピュア陣営がフェイク陣営と同数以下まで減るとフェイク陣営の勝ちです。

## 役職

| 役職 | 陣営 | 能力・特徴 |
|---|---|---|
| 見習い占い師 | ピュア | 夜に1人の陣営を調べる |
| 守り手 | ピュア | 夜に1人を襲撃から守る（自分も可） |
| 追跡係 | ピュア | 夜に1人が「誰を訪ねたか」を知る |
| うっかり占い師 | ピュア | 占い結果が45%の確率でランダムにズレる |
| 村ガール | ピュア | 能力なし。議論と投票で戦う |
| フェイクガール | フェイク | 夜に1人を脱落させる（襲撃は陣営で1回） |
| なりすまし | フェイク | 調査されると65%の確率でピュア判定に化ける |
| バカ | ピュア | 本人には別のピュア役職が表示され、その役職として夜行動する。脱落時に実役職が公開される |

キャラクターは ルナ、ミオ、ユイ、カノン、スズ、リリ、ノア、エマ の8人です。

## 技術メモ

- `index.html` の単一ファイル構成（HTML / CSS / JavaScript、ビルド不要）
- ローカルで試す場合は `index.html` をブラウザで開くだけで動作します
- GitHub Pages で `main` ブランチのルートを公開しています
