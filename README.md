# Fake Bloom

イノセント陣営とインポスター陣営に分かれて戦う、ブラウザで遊べる正体隠匿（人狼系）ゲームです。
ソロ（あなた1人＋CPU7人）でも、パス＆プレイ（2〜8人で1台の端末を回す対面プレイ）でも遊べます。インストール不要・ビルド不要で動作します。

**▶ 遊ぶ： https://kawahara-dev.github.io/baka_jinrow_ppoi/**

## 遊び方

1. START を押してゲーム開始。自分の役職が表示されます。
2. フェーズは **夜行動 → 朝の報告 → 昼の議論 → 投票** の繰り返しです。
3. 夜は役職の能力（調査・護衛・追跡・襲撃など）を使い、昼は発言とログの矛盾を探して、投票で怪しい1人を追放します。
4. インポスター陣営を全員追放すればイノセント陣営の勝ち。イノセント陣営がインポスター陣営と同数以下まで減るとインポスター陣営の勝ちです。

## パス＆プレイ

- タイトル画面の設定で「遊び方：パス＆プレイ」を選ぶと、2〜8人で1台の端末を回して対面で遊べます。
- 役職は受け渡し画面で順番に確認し、夜行動と投票も順番に入力します（カバー画面つきで他人の役職・夜結果・投票先は見えません）。
- 議論は口頭で行い、タイマー（設定で なし／1分／2分／3分）で時間を計れます。時間切れでも自動では投票へ進みません。
- CPU の自動発言は人間の人数に応じて減ります。戦績はソロと別に記録されます。

## その他

- 難易度（かんたん／ふつう／つよい）で CPU の強さを変えられます。インポスター人数（1〜2人）やボマーの有無も設定できます。
- 戦績と実績（11種）がタイトル画面で見られます。効果音と BGM（WebAudio 生成の環境音）のオン／オフも設定できます。
- セリフと行動ログは見出しをタップして折りたためます（状態は端末に保存されます）。

## 役職

| 役職 | 陣営 | 能力・特徴 |
|---|---|---|
| 見習い占い師 | イノセント | 夜に1人の陣営を調べる。結果がズレる個体が混ざることがある（本人にも分からない） |
| 守り手 | イノセント | 夜に1人を襲撃から守る（自分も可） |
| 追跡係 | イノセント | 夜に1人が「誰を訪ねたか」を知る |
| 村ガール | イノセント | 能力なし。議論と投票で戦う |
| ポリス | イノセント | 夜に1人を訪ねて、その夜の行動を封じる（インポスター陣営の襲撃そのものは止められない）。イノセント側の役職は抽選で登場 |
| 見張り役 | イノセント | 夜に1人の家を見張り、その夜に訪れた全員が分かる。イノセント側の役職は抽選で登場 |
| トラッパー | イノセント | 夜に1人の家へ罠を設置。その人が襲撃されて倒れたら、襲撃者も道連れになる。イノセント側の役職は抽選で登場 |
| ドクター | イノセント | 夜に1人を診察。その人がその夜に襲撃や爆発で倒れたら、朝までに蘇生させる。イノセント側の役職は抽選で登場 |
| マウス | イノセント | 昼の役職。ゲーム中1回だけ、議論中に1人の本当の役職を全員に公開できる。イノセント側の役職は抽選で登場 |
| 政治家 | イノセント | 投票の役職。自分の票が常に2票分になる。イノセント側の役職は抽選で登場 |
| フェイクガール | インポスター | 夜に1人を脱落させる（襲撃は陣営で1回）。襲撃しない夜は、イノセント側1人の夜行動を妨害する |
| なりすまし | インポスター | 調査されると65%の確率でイノセント判定に化ける。襲撃も担当でき、襲撃しない夜はイノセント側1人の実役職を盗み見する（陣営はその情報を襲撃先の決定に使う） |
| ボマー | ニュートラル | 第三勢力。約半分のゲームに登場。夜に1人へ爆弾を仕掛け、翌日の夜に爆発する（護衛されていると不発）。どちらの陣営の勝利条件にも数えられず、最後の1人になるか、爆弾で2人以上を倒して生き残ると勝利 |
| バカ | イノセント | 本人は別のイノセント役職だと思って行動する。ただし行動結果はすべて偽物（占い判定はランダム、護衛は実際には守れない、追跡・見張り情報もデタラメ、ポリスの妨害・トラッパーの罠・ドクターの蘇生・マウスの公開もすべて空振りや偽物になる）。本人も自分がバカだとは分からず、実役職は結果画面でのみ公開される |

キャラクターは ルナ、ミオ、ユイ、カノン、スズ、リリ、ノア、エマ の8人です。

## 技術メモ

- `index.html` が画面とゲーム進行を担う単一ファイル構成（HTML / CSS / JavaScript、ビルド不要）。役職データやキャラ別セリフなど DOM を使わない純粋な部分は、Node でもブラウザでも動く共有モジュール `game-logic.js` に切り出してあり、オンライン対戦（`docs/online-multiplayer.md` のフェーズ0）でサーバー側と共用する土台です
- タイトル画面では、8人のキャラクターが「てちてち歩行」のパレードアニメーションで横切る。各キャラに全身イラストの歩行2ポーズ（左足前／右足前）を用意し、フレーム切り替え＋体の上下動で本当に足を運んで歩くように見せている。歩行用画像はバイナリを直接置けない都合で `walk/<名前>_a.b64` / `_b.b64`（base64テキスト）として保存し、ページ読み込み時に data URI へ復元している
- ローカルで試す場合は `index.html` をブラウザで開くだけで動作します
- GitHub Pages で `main` ブランチのルートを公開しています

### テスト

`tests/` に Node 標準のテストランナー（`node:test`）による自動テストがあります。依存パッケージは不要で、Node 18以上があれば実行できます。

```sh
node --test   # リポジトリのルートで実行（tests/*.test.js を自動検出）
```

`tests/harness.js` が `game-logic.js` を先に読んでから `index.html` の `<script>` を読み、IIFE の外枠だけを外して DOM スタブ付きの `vm` コンテキストで実行します（jsdom 不要）。テスト側は `setupGame` / `runNight` / `resolveNightActions` / `doVote` / `checkWin` などのゲーム内部を直接呼び、以下を検証します。

- 役職の配分（8人・バカ1人・占い師1人・インポスター人数が設定通り）
- 勝敗条件（イノセント／インポスター／ボマーの単独勝利・横取り勝利）
- 夜行動の解決（守り手の防衛、罠の道連れ、ドクターの蘇生、占い・なりすまし・バカの判定）
- マウスの役職公開
- 各種設定（インポスター人数・ボマー・難易度）でのフルゲーム完走と戦績の記録
- パス＆プレイ（人間2〜8人）のフルゲーム完走と、のぞき見防止（他人の役職・夜結果・投票先が画面表示・ログに出ないこと）
- 共有モジュール `game-logic.js`（`tests/logic-module.test.js`）：DOM なしの素の Node で読み込めること、役職データ・キャラ別セリフ・役職判定・旧戦績の移行が正しいこと、ブラウザ側のゲームと内容が一致すること
